# Moto Hana — مشروع Android

تطبيق Android مستقل يعمل محليًا، بدون Backend أو اشتراك أو API خارجي.

## متطلبات البناء
- Android Studio أو GitHub Actions.
- JDK 17.
- Android SDK Platform 35 وBuild Tools 35.0.0.
- Gradle 8.9 (يتم توليد Gradle Wrapper في Workflow).

## البناء عبر GitHub
1. ارفع محتويات هذا المجلد إلى جذر المستودع.
2. تأكد من وجود `.github/workflows/android.yml`.
3. ادفع التعديلات إلى `main` أو `master`.
4. افتح Actions ثم نزّل Artifact باسم `MotoHana-debug-apk` عند نجاح البناء.

## البناء محليًا من VS Code / PowerShell
بعد تثبيت Android SDK وJDK 17:

```powershell
gradle wrapper --gradle-version 8.9
.\gradlew.bat --no-daemon clean assembleDebug
```

ملف APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## الوظائف الموجودة في هذه النسخة
- إعداد PIN لأول تشغيل وتسجيل الدخول به.
- فتح التطبيق بالبصمة؛ عند نجاح التحقق يتم الانتقال مباشرة إلى الشاشة الرئيسية.
- واجهة داكنة مقسمة إلى الرئيسية والمهام والإجراءات والسجل والإعدادات.
- اختيار التطبيقات التي يسمح بقراءة إشعاراتها، والتقاط الإشعار الذي يحتوي اسم المساعد.
- إنشاء التذكيرات يدويًا وجدولتها محليًا واستعادتها بعد إعادة تشغيل الهاتف.
- تحديد الموقع الحالي وعرض الإحداثيات ورابط Google Maps.
- إعداد رسالة SMS بالموقع، واختيار SIM1 أو SIM2، ومراجعة الرسالة والموافقة قبل الإرسال.

## وظائف لم تكتمل بعد — لا تعتبرها مدعومة
- محرك فهم شامل للأوامر العربية الحرة.
- تحويل أوامر المكالمات الواردة من الإشعارات إلى مهام اتصال مجدولة.
- تنفيذ أوامر النظام المقيدة مثل تبديل بيانات الهاتف أو وضع الطيران.
- إرسال WhatsApp أو Live Location دون تدخل المستخدم.
- منع إلغاء تثبيت التطبيق أو مسح بياناته.

## حدود Android
- تطبيق عادي لا يستطيع منع المستخدم من إلغاء تثبيته أو مسح بياناته.
- بدء المكالمات من الخلفية يخضع لقيود Android؛ يمكن عرض إشعار/واجهة اتصال بدل الاتصال الصامت.
- Android الحديث لا يسمح للتطبيقات العادية بتغيير وضع الطيران أو بيانات الهاتف مباشرة.
- WhatsApp لا يوفر API عامة لإرسال الرسائل الشخصية أو Live Location تلقائيًا.
- إرسال SMS قد يترتب عليه تكلفة من شركة الاتصالات. يطلب التطبيق موافقة صريحة قبل الإرسال، ولا يستطيع ضمان معرفة السعر مسبقًا.

## ملاحظة اختبار
نجاح GitHub Actions يثبت نجاح الترجمة فقط، ولا يثبت عمل كل صلاحية أو وظيفة على كل جهاز. اختبر PIN والبصمة والإشعارات والموقع وSIM/SMS على الهاتف قبل الاعتماد.
