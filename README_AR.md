# موتو حنا — مشروع Android تأسيسي

مشروع مستقل عن MyAIAgent Pro، بحزمة `com.motohana.assistant` واسم عرض «موتو حنا».

## فتح وبناء المشروع
1. فك ضغط الملف.
2. افتح مجلد `MotoHanaAssistant` باستخدام Android Studio.
3. ثبّت JDK 17 وAndroid SDK 35 عند الطلب.
4. نفّذ Gradle Sync ثم Build > Build APK(s).

## الموجود في النسخة الحالية
- واجهة عربية داكنة.
- طلب صلاحيات الموقع وSMS وقراءة حالة الشرائح.
- تحديد الموقع عبر Google Fused Location Provider.
- تكوين رسالة تحتوي على الإحداثيات ورابط Google Maps.
- اختيار SIM1 أو SIM2 عبر SubscriptionManager.
- طلب موافقة صريحة قبل محاولة إرسال SMS.
- نقطة استقبال أولية لإشعارات التطبيقات.
- اختبار التحقق البيومتري.

## ما زال قيد الاستكمال
PIN آمن وربطه بفتح التطبيق، اختيار التطبيقات المسموح بمراقبتها، محلل أوامر عربي محلي، قاعدة بيانات المهام والسجل، جدولة واستعادة التذكيرات، واجهات تنفيذ WhatsApp والمكالمات والإجراءات المتاحة على Android.

## حدود المنصة
- لا توجد واجهة موحدة تضمن معرفة سعر SMS قبل الإرسال؛ لذلك يعرض التطبيق تحذير تكلفة ويطلب موافقتك قبل كل محاولة.
- تحديد SIM يحتاج صلاحيات ودعمًا من الجهاز، وقد تختلف السلوكيات حسب الشركة المصنعة.
- التطبيق العادي لا يستطيع منع إلغاء التثبيت أو مسح بياناته منعًا مطلقًا.
- لا يحتوي المشروع على Backend أو API لإرسال بياناتك إلى خادم.

## GitHub Actions
أُضيف ملف Workflow في `.github/workflows/android.yml` للبناء عند Push إلى `main` أو `master` أو يدويًا من تبويب Actions.
ملاحظة: المشروع الحالي لا يحتوي Gradle Wrapper (`gradlew` وملفات `gradle/wrapper`)، لذلك يلزم توليدها مرة واحدة من Android Studio أو بأمر `gradle wrapper` قبل أن ينجح البناء على GitHub Actions.
