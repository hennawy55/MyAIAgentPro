# موتو حنا — إعادة بناء مستقلة

- اسم التطبيق: موتو حنا
- Package: `com.motohana.assistant`
- Kotlin + Android Views (بدون Compose)
- Android SDK 35 / JDK 17 / Gradle 8.9
- يعمل محليًا ولا يحتوي Backend أو API.

## البناء من GitHub
1. ارفع محتويات هذا المجلد إلى المستودع.
2. افتح Actions وشغّل `Build Moto Hana APK` أو ادفع commit جديدًا.
3. حمّل `MotoHana-debug-apk` من Artifacts.

## الوظائف الموجودة
- إنشاء PIN عند أول تشغيل وتخزين hash مملح محليًا.
- تسجيل الدخول بالـ PIN، وخيار تحقق بيومتري.
- تعيين اسم المساعد.
- شاشة اختيار التطبيقات التي ستُقبل إشعاراتها.
- NotificationListenerService يلتقط الإشعار إذا احتوى اسم المساعد ويحفظ آخر أمر محليًا.
- إنشاء تذكيرات بموعد محدد، إشعار عند حلول الموعد، حذف التذكير واستعادة المواعيد بعد إعادة التشغيل.
- تحديد الموقع، إظهار الإحداثيات ورابط Google Maps.
- إنشاء رسالة SMS واختيار SIM1/SIM2، مع موافقة صريحة قبل الإرسال.
- روابط إعدادات الموقع والشبكة.
- لا يرسل أي بيانات إلى خادم.

## خطوات الإعداد بعد التثبيت
1. افتح التطبيق وأنشئ PIN.
2. من إدارة الصلاحيات امنح الموقع وSMS وقراءة حالة الهاتف والإشعارات عند الحاجة.
3. فعّل خدمة قراءة الإشعارات من إعدادات Android.
4. اختر التطبيقات المسموح بمراقبتها.
5. اضبط اسم المساعد.

## قيود معلنة
- التقاط الإشعار وتسجيل نصه موجود؛ تنفيذ كل صياغات الأوامر الطبيعية وتحويلها تلقائيًا إلى مهام لم يكتمل بعد في هذا الإصدار.
- لا يستطيع تطبيق عادي منع إلغاء التثبيت أو مسح بيانات التطبيق.
- Android الحديث يمنع التطبيقات العادية من تغيير وضع الطيران وبيانات الهاتف مباشرة.
- WhatsApp لا يوفر API عامة لإرسال الرسائل الشخصية أو Live Location آليًا.
- سعر SMS النهائي يحدده مشغل الشبكة؛ التطبيق يطلب موافقة قبل الإرسال لكنه لا يستطيع ضمان معرفة السعر مسبقًا.
- اختيار الشريحة يتطلب دعم الجهاز وصلاحية قراءة حالة الهاتف.
- Exact alarms قد تتطلب إذنًا خاصًا من إعدادات Android؛ عند عدم توفره يستخدم التطبيق منبهًا غير دقيق نسبيًا.

## ملاحظات اختبار
المشروع أعيدت كتابته لتجنب Compose ومشكلات setContent السابقة. يجب تشغيل GitHub Actions للتأكد من نجاح بناء APK في بيئة Android SDK فعلية، ثم اختباره على الهاتف. نجاح البناء وحده لا يثبت عمل كل صلاحية على كل جهاز.
